# Agent Trace API - Quick Reference

Quick reference guide for Agent Trace API endpoints.

## Base URL

```
http://localhost:8100/api/v1/trace
```

## Authentication

All endpoints require API key authentication:

```bash
-H "X-API-Key: your-api-key"
```

## Endpoints

### Health Check

```bash
GET /trace/health
```

Returns trace subsystem status and basic statistics.

### File Attributions

```bash
GET /trace/files/{file_path}?limit=100&offset=0
```

Get all code attributions for a specific file.

**Example:**
```bash
curl -H "X-API-Key: your-key" \
  "http://localhost:8100/api/v1/trace/files/app%2Fapi%2Ftrace_routes.py?limit=50"
```

### Agent Attributions

```bash
GET /trace/agents/{agent_id}?limit=100&offset=0
```

Get all code generated by a specific agent.

**Example:**
```bash
curl -H "X-API-Key: your-key" \
  "http://localhost:8100/api/v1/trace/agents/claude-sonnet"
```

### Session Attributions

```bash
GET /trace/sessions/{session_id}?limit=100&offset=0
```

Get all code generated in a specific session/conversation.

**Example:**
```bash
curl -H "X-API-Key: your-key" \
  "http://localhost:8100/api/v1/trace/sessions/conv-123"
```

### Recent Attributions

```bash
GET /trace/recent?days=7&limit=100&offset=0
```

Get recent code attributions (1-90 days).

**Example:**
```bash
curl -H "X-API-Key: your-key" \
  "http://localhost:8100/api/v1/trace/recent?days=7&limit=50"
```

### Statistics

```bash
GET /trace/stats
```

Get comprehensive attribution statistics.

**Example:**
```bash
curl -H "X-API-Key: your-key" \
  "http://localhost:8100/api/v1/trace/stats"
```

### Generate Report

```bash
POST /trace/report
Content-Type: application/json

{
  "agentId": "claude-sonnet",
  "filePath": "/app/api",
  "changeType": "generation",
  "startDate": "2026-01-01",
  "endDate": "2026-01-31",
  "format": "json|csv|pdf"
}
```

Generate compliance report with filters.

**Example (JSON):**
```bash
curl -X POST -H "X-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{
    "agentId": "claude-sonnet",
    "startDate": "2026-01-01",
    "endDate": "2026-01-31",
    "format": "json"
  }' \
  "http://localhost:8100/api/v1/trace/report"
```

**Example (CSV):**
```bash
curl -X POST -H "X-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{
    "format": "csv",
    "changeType": "generation"
  }' \
  "http://localhost:8100/api/v1/trace/report" \
  -o report.csv
```

## Common Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `limit` | int | 100 | Max results (1-1000) |
| `offset` | int | 0 | Pagination offset |
| `days` | int | 1 | Days to look back (1-90) |

## Report Filters

| Filter | Type | Description |
|--------|------|-------------|
| `agentId` | string | Filter by agent |
| `filePath` | string | Filter by file path (partial match) |
| `changeType` | string | Filter by type (generation/edit/deletion) |
| `startDate` | string | Start date (YYYY-MM-DD) |
| `endDate` | string | End date (YYYY-MM-DD) |
| `format` | string | Output format (json/csv/pdf) |

## Error Responses

### 404 Not Found

```json
{
  "detail": "No attributions found for file: /app/api/missing.py"
}
```

### 400 Bad Request

```json
{
  "detail": "Invalid startDate format. Use YYYY-MM-DD"
}
```

### 401 Unauthorized

```json
{
  "detail": "Invalid or missing API key"
}
```

### 503 Service Unavailable

```json
{
  "detail": "Agent Trace subsystem unhealthy: database connection failed"
}
```

## Python SDK Example

```python
import httpx

async with httpx.AsyncClient() as client:
    # Get stats
    response = await client.get(
        "http://localhost:8100/api/v1/trace/stats",
        headers={"X-API-Key": "your-api-key"}
    )
    stats = response.json()

    # Get file attributions
    response = await client.get(
        "http://localhost:8100/api/v1/trace/files/app/api/trace_routes.py",
        headers={"X-API-Key": "your-api-key"}
    )
    file_data = response.json()

    # Generate report
    response = await client.post(
        "http://localhost:8100/api/v1/trace/report",
        json={
            "format": "json",
            "startDate": "2026-01-01"
        },
        headers={"X-API-Key": "your-api-key"}
    )
    report = response.json()
```
